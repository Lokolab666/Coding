# Developer Job Description
Top 4 things (at least 2 years required for each)
* Java (JEE)
* Groovy and/or Grails
* Javascript
* SQL

### Excellent verbal and written communication skills required.

Responsibilities may include the following and other duties may be assigned. Responsible for developing or modifying web-based applications for functional areas including quality, human resources and marketing. Follow existing development practices using Java and Grails, and other approved frameworks. Work as part of an Agile development team and provide self-direction for completing required tasks. Understanding functional requirements from users and translating those to development tasks and stories. Writing unit test to ensure code quality and work with testing resources to prioritize and resolve defects. Balance multiple project work and priorities simultaneously.
_Excellent verbal and written English communication required._


__Required Knowledge and Experience:__
- Bachelor's degree required
- Requires 2 or more years of experience in web development.
- Thorough knowledge and demonstrated use of Java required.
- Knowledge of Groovy and/or Grails needed.
- Competent with source code control using Git.

Technical skills most candidates will have: Java, JEE, Groovy, Grails, Git, HTML5, Javascript (and Javascript frameworks like jQuery), WebLogic and/or Tomcat application server, Oracle SQL
Requires practical knowledge and demonstrated competence within the job area typically obtained through advanced education combined with experience.

# Technical Lead/Solution Architect Job Description
Top 4 things (at least 5 years required for each)
* Java (JEE)
* Groovy and/or Grails
* Javascript
* SQL

### Excellent verbal and written communication skills required.

Responsibilities may include the following and other duties may be assigned. Responsible for developing or modifying web-based applications for functional areas
including supplier management, quality, human resources and marketing. Follow existing development practices using Java and Grails, and other approved frameworks.
Work as part of an Agile development team and provide self-direction for completing required tasks. Understanding functional requirements from users and
translating those to development tasks and stories. Writing unit test to ensure code quality and work with testing resources to prioritize and resolve defects.
Balance multiple project work and priorities simultaneously.

As a technical lead, provide guidance for more junior developers.  This includes code reviews, data architecture guidance and resolving roadblocks related to the environment.
Often times this requires interfacing with other teams such as: DBAs, Integration Team and Identity & Access Management Team.  Also review security aspects of the code including resolving identified vulnerabilities.
Ensure that company standards are followed for source code management and versioning.

_Excellent verbal and written English communication required._


__Required Knowledge and Experience:__
- Bachelor's degree required
- Requires 5 or more years of experience in web development.
- Thorough knowledge and demonstrated use of Java required.
- Knowledge of Groovy and/or Grails needed.
- Competent with source code control using Git.

Technical skills most candidates will have: Java, JEE, Groovy, Grails, Git, HTML5, Javascript (and Javascript frameworks like jQuery), WebLogic and/or Tomcat application server, Oracle SQL, OpenID Connect.
Requires practical knowledge and demonstrated competence within the job area typically obtained through advanced education combined with experience.
