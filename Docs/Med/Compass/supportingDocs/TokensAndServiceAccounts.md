# Service Accounts #
Below outlines the current list of service accounts used by various projects tied to the Compass CI product / pipelines and how to update them.

## How to Update ##
1. Sign into your computer.
2. If working remotely, connect to Ivanti Secure VPN on a Windows PC.
3. Press Ctrl + Alt + Del and select Change a Password.
4. Enter `ENT\<service account username>`, existing (Old) password, the new password, and confirm the new password.
    * Passwwords should be at least 15 characters long.
    * Use random password generator such as: https://www.lastpass.com/features/password-generator
5. Click Submit, or press Enter.
A message will appear if the password change request is successful.

__If you need assistance with the reset:__
Create a ServiceNow Incident and assign to  `Accounts AD Admin-US` to assist with password reset.

__If you feel there is a more appropriate owner for this Service Account, or if the account is no longer needed:__
Complete this [form](https://medtronicprod.service-now.com/it/?id=mdtit_sc_cat_item&sys_id=14721b7a4fd29a002ebc7bcd0210c77e) to take the most appropriate action.
