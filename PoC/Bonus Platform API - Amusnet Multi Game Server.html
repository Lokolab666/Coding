    Award Manual Bonus

    This method is used whenever the Casino Operator would like to award Bonus directly to specified Player without creating a tracked Promotion.

    Authorizations:
    ApiKeyAuth
    Request Body schema: application/json
    required

    The settings needed for awarding a Bonus to a group of players.

    id
    required
    string <uuid>

    The idempotency key of the request. Must be a UUID represented by a standard 36-char string.

    playerIds
    required
    Array of strings [ 1 .. 5000 ] items [ items [ 1 .. 64 ] characters ]

    The identifiers of the players to be awarded this bonus. A maximum of 5 000 (five thousand) players may be awarded per request. If the total number of players exceeds this limit, split the request into multiple batches.

    skinName
    required
    string [ 1 .. 128 ] characters

    The name of the players' skin.

    amount
    integer <int64> > 0

    The quantity of bonuses being awarded per player. Constraints: The parameter is required for all award types except COUNTDOWN_FREE_SPIN or CASH_REWARD, for which it must be omitted or set to null. The parameter must be set to 1 for FREE_BUY_BONUS.

    type
    required
    string
    Enum: "FREE_SPIN" "FREE_BUY_BONUS" "GOLDEN_CHIP" "COUNTDOWN_FREE_SPIN"

    The type of the bonuses being awarded.

    object

    Any additional configuration details needed for the specified bonus type.

    betValueStrategy
    required
    string
    Enum: "MINIMUM" "EXACT" "CLOSEST" "CLOSEST_LOWER" "CLOSEST_HIGHER"

    The strategy used for determining the bet value. Constraints: The parameter is required for all Bonus Types except CASH_REWARD, for which it must be omitted or set to null.

    betValue
    number > 0

    The value of the bonuses awarded. The parameter may be omitted if the Bet Value Strategy used is MINIMUM. For any other Bet Value Strategy, the parameter is required. New Constraint: The parameter must be omitted or set to null for Bonus Type CASH_REWARD.

    currency
    required
    string = 3 characters

    The currency code for the bonuses, defined by the three-letter currency code as per ISO-4217.

    games
    required
    Array of integers <int32> [ 1 .. 1000 ] items [ items <int32 > > 0 ]

    The unique identifiers of the games eligible for the bonuses.

    claimByStrategy
    string
    Enum: "RELATIVE_TO_AWARD" "CUSTOM"

    The strategy for determining the deadline by which the bonuses must be claimed.

    claimByMinutes
    integer <int64> [ 0 .. 1440000 ]

    The number of minutes the bonuses are available to be claimed after being awarded. Required if Award Manual Bonuses Claim By Strategy is RELATIVE_TO_AWARD.

    claimByDateTime
    string <date-time>

    The deadline by which bonuses must be claimed. (UTC time zone)

    expirationStrategy
    string
    Enum: "RELATIVE_TO_CLAIM" "CUSTOM"

    The strategy for determining when the bonuses will expire.

    expirationMinutes
    integer <int64> ( 0 .. 1440000 ]

    The number of minutes the bonus is valid for after being claimed. Required if expirationStrategy is RELATIVE_TO_CLAIM.

    expirationDateTime
    string <date-time>

    The exact date when the bonus will expire. Required if expirationStrategy is CUSTOM.

    Responses

    Amusnet MGS URL

    https://{amusnet-mgs-domain}/bonus-platform/operator/v1/bonuses

    Retrieve Bonuses

    This method is used whenever the Casino Operator would like to retrieve a list of Bonuses using diverse identifiers.

    Authorizations:
    ApiKeyAuth
    query Parameters
    id
    string

    Filter bonuses by their unique identifier.

    groupId
    string

    Filter bonuses by the unique identifier of their associated group.

    groupTypes
    Array of strings (GroupType)
    Items Enum: "PROMOTION" "TOURNAMENT" "MISSION" "MANUAL"

    Filter bonuses by their group types.

    sourceId
    string

    Filter bonuses by the unique identifier of their associated source promotional tool (ex. Promotion ID or Tournament ID).

    playerId
    string

    Filter bonuses by the player's identifier.

    types
    Array of strings (BonusType)
    Items Enum: "FREE_SPIN" "FREE_BUY_BONUS" "LUCKY_SPIN" "GOLDEN_CHIP" "COUNTDOWN_FREE_SPIN"

    Filter bonuses by their types.

    states
    Array of strings (BonusState)
    Items Enum: "AWARDED" "CLAIMED" "IN_PLAY" "CONSUMED" "REVERTED" "UNCLAIMED" "EXPIRED" "DECLINED" "REVOKED"

    Filter bonuses by their states.

    used
    boolean

    Filter bonuses based on whether they have been used.

    activeFrom
    string <date-time>

    Filter bonuses by their active period start date.

    activeTo
    string <date-time>

    Filter bonuses by their active period end date.

    expiredFrom
    string <date-time>

    Filter bonuses by their expiration period start date.

    expiredTo
    string <date-time>

    Filter bonuses by their expiration period end date.

    games
    Array of integers <int32> [ items <int32 > ]

    Filter bonuses by the unique identifiers of eligible games.

    portalUids
    Array of strings <int64> [ items <int64 > ]

    Filter bonuses by associated portal unique identifiers.

    currency
    string

    Filter bonuses by their currency code (ISO-4217 format).

    createdFrom
    string <date-time>

    Filter bonuses by their creation date start range.

    createdTo
    string <date-time>

    Filter bonuses by their creation date end range.

    offset
    integer <int64> >= 0

    Set the pagination offset, specifying the number of records to skip.

    limit
    integer <int64> > 0

    Set the pagination limit, specifying the maximum number of records to return.

    Revert an amount from a given Bonus

    path Parameters

    required

    Request Body schema: application/json
    required

    The settings needed for reverting an amount from a Bonus.

    id
    required
    string <uuid>

    The idempotency key of the request. Must be a UUID represented by a standard 36-char string.

    Create Promotion

    This method is used whenever the Casino Operator would like to create a Promotion.

    Authorizations:
    ApiKeyAuth
    Request Body schema: application/json
    required

    The settings needed for creating a new promotion.

    id
    required
    string <uuid>

    The idempotency key of the request. Must be a UUID represented by a standard 36-char string.

    name
    required
    string [ 1 .. 128 ] characters

    The name of the promotion.

    displayName
    string [ 1 .. 128 ] characters

    The optional display name of the promotion.

    description
    string <= 512 characters

    An optional description of the promotion.

    currency
    required
    string = 3 characters

    The main currency code for the promotion, defined by the three-letter currency code as per ISO-4217.

    additionalCurrencies
    required
    Array of strings <= 200 items [ items = 3 characters ]

    Additional currencies supported by the promotion, defined by the three-letter currency code as per ISO-4217.

    triggerType
    required
    string
    Enum: "NONE" "START_DATE" "CHANCE_PER_STAKE" "CASHBACK"

    The method by which bonuses are awarded in the promotion.

    object

    Any additional configuration details needed for the specified trigger type.

    enrolmentType
    required
    string
    Enum: "NONE" "OPT_IN"

    The method by which players can be enrolled to this promotion.

    publishDateTime
    string <date-time>

    The publishing date and time of the promotion.. (UTC time zone)

    startDateTime
    string <date-time>

    The start date and time of the promotion. (UTC time zone)

    endDateTime
    string <date-time>

    The end date and time of the promotion. (UTC time zone)

    displayUntil
    string <date-time>

    The display until date and time after the end date of the promotion. (UTC time zone)

    Array of objects (PromotionLivePeriod) [ 1 .. 100 ] items

    Defines a list of time windows during which the promotion is live.

    required
    Array of objects (CreateSkinPlayers) [ 1 .. 50 ] items

    Defines player eligibility for the promotion segregated by skin.

    games
    required
    Array of integers <int32> [ 1 .. 1000 ] items [ items <int32 > > 0 ]

    The unique identifiers of the games eligible for the bonuses of this promotion.

    includeBonusMoney
    boolean

    Indicates whether bonus money transfers are eligible to be processed by the promotion. If the parameter is not provided, it automatically defaults to true.

    publishBudget
    boolean
    Default: false

    Indicates whether the promotion should publish its budget.

    bonusType
    required
    string
    Enum: "FREE_SPIN" "FREE_BUY_BONUS" "LUCKY_SPIN" "GOLDEN_CHIP" "COUNTDOWN_FREE_SPIN" "CASH_REWARD"

    The type of the bonuses awarded from this promotion.

    object

    Any additional configuration details needed for the specified bonus type.

    bonusClaimByStrategy
    string
    Enum: "RELATIVE_TO_AWARD" "CUSTOM"

    The strategy for determining the deadline by which the bonuses awarded from this promotion must be claimed, if applicable.

    bonusClaimByMinutes
    integer <int64> [ 0 .. 1440000 ]

    The number of minutes the bonuses awarded from this promotion are available to be claimed after being awarded. Required if bonusClaimByStrategy is RELATIVE_TO_AWARD.

    bonusClaimByDateTime
    string <date-time>

    The deadline by which the bonuses awarded from this promotion must be claimed. Required if bonusClaimByStrategy is CUSTOM.

    bonusExpirationStrategy
    string
    Enum: "RELATIVE_TO_CLAIM" "CUSTOM"

    The strategy for determining when bonuses awarded from this promotion will expire.

    bonusExpirationMinutes
    integer <int64> ( 0 .. 1440000 ]

    The number of minutes a bonus awarded from this promotion will be valid for after being claimed. Required if bonusExpirationStrategy is RELATIVE_TO_CLAIM.

    bonusExpirationDateTime
    string <date-time>

    The exact date when the bonuses awarded from this promotion will expire. Required if bonusExpirationStrategy is CUSTOM.

    required
    Array of objects (CreateBonusSet) [ 1 .. 5000 ] items

    Defines distinct templates that specify the characteristics and limits of the bonuses awarded from this configuration.

    portalNames
    required
    Array of strings [ 1 .. 50 ] items [ items [ 1 .. 128 ] characters ]

    The names of the portals participating in the promotion.

    Responses

    Amusnet MGS URL

    https://{amusnet-mgs-domain}/bonus-platform/operator/v1/promotions
